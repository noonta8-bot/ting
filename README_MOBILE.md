# เชื่อมเกจกับมือถือ (Android + iOS) — แนวนอน

เกจปล่อย Wi-Fi ชื่อ **NUI-GAUGE** (รหัส **12345678** แก้ได้ใน `include/config.h` → `MOBILE_SSID / MOBILE_PASS / MOBILE_CH`)
มือถือต่อ Wi-Fi นี้ แล้วเห็น **หน้าจอเหมือนเกจทุกพิกเซล ทุกหน้า ทุกเมนู** แตะ/ปัดบนมือถือ = แตะ/ปัดบนเกจ
และส่ง **ความเร็วจาก GPS มือถือ** ไปขึ้นช่อง SPEED ของเกจ (ป้าย SPEED เปลี่ยนเป็น GPS ตอนใช้ค่าจากมือถือ)

## วิธีใช้งานเร็ว (ไม่ต้องสร้างแอป) — ได้ทุกอย่างยกเว้น GPS
1. อัปโหลดเฟิร์มแวร์ตามปกติ (`pio run -t upload`)
2. มือถือต่อ Wi-Fi **NUI-GAUGE** (ถ้ามือถือถามว่า "ไม่มีอินเทอร์เน็ต" ให้เลือก *คงการเชื่อมต่อไว้*)
3. เปิดเบราว์เซอร์ไปที่ `http://192.168.4.1` → หมุนมือถือเป็นแนวนอน (ถ้าถือแนวตั้ง หน้าจะหมุนให้เอง)
4. ปุ่มเฟืองมุมขวาบน (แตะจอให้ขึ้น) = ตั้งค่า / เต็มจอ / ค้างหน้าจอ
> เบราว์เซอร์ไม่อนุญาต GPS บนหน้า `http://` (ต้อง https) จึงต้องใช้แอปด้านล่างถ้าต้องการวัดความเร็วจากมือถือ

## แอปมือถือ (มี GPS) — Capacitor ตัวเดียว ใช้ได้ทั้ง Android และ iOS
ต้องมี Node.js 18+ ; Android ใช้ Android Studio (Windows/Mac/Linux) ; **iOS ต้องใช้ Mac + Xcode** (Apple ID ฟรีได้ แต่แอปหมดอายุทุก 7 วัน)
```
cd mobile
npm install
npx cap add android        # และ/หรือ  npx cap add ios
python3 patch_native.py    # บังคับแนวนอน + อนุญาต ws:// + ขอสิทธิ์ GPS
npx cap sync
npx cap open android       # หรือ ios  -> กด Run ใน Android Studio / Xcode
```
ถ้าแก้ `mobile/www/index.html` ให้รัน `python tools/embed_web.py` (อัปเดตหน้าเว็บที่ฝังในเฟิร์มแวร์) แล้ว `npx cap sync` อีกครั้ง

## ตั้งค่าที่เกจ
เมนู **SYS → PHONE LINK** : เปิด/ปิด Wi-Fi, ดูชื่อ/รหัส/จำนวนมือถือที่ต่อ, เลือกแหล่งความเร็ว
- **AUTO** = ใช้ GPS มือถือเมื่อมีสัญญาณ ไม่งั้นใช้ความเร็วจาก ECU (ค่าเริ่มต้น)
- **ECU** = ใช้ค่า ECU อย่างเดียว  - **PHONE** = ใช้ GPS มือถืออย่างเดียว (ไม่มีสัญญาณ = แสดง --)
GPS ที่เก่าเกิน 3 วินาทีถือว่าขาดสัญญาณ

## ข้อจำกัดที่ควรรู้ (ยังไม่ได้ทดสอบกับเกจจริง)
- โค้ดเฟิร์มแวร์ฝั่งเครือข่าย **ยังไม่ได้คอมไพล์กับ PlatformIO จริง** (เครื่องที่เขียนไม่มี toolchain ESP32) — ทดสอบด้วยตัวจำลองบนคอมพิวเตอร์: ภาพที่มือถือสร้างตรงกับจอเกจทุกพิกเซลใน 72 กรณี (9 หน้า × 2 ภาษา × 2 ค่าข้อมูล × เข้าทันที/ต่อกลางคัน) และตรรกะคำสั่งแตะ/ปัด/GPS ผ่าน แต่ **ความเร็ว/ความเสถียรของ Wi-Fi จริง** ต้องลองบนเครื่อง ถ้าคอมไพล์ไม่ผ่านบอกข้อความ error ได้เลย
- Wi-Fi ของ ESP32 ทำงานบน core 0 เดียวกับงานอ่าน ECU (task ของมือถือความสำคัญต่ำกว่า) — ถ้าอัตราอ่าน ECU ตกตอนต่อมือถือ ให้ปิด Wi-Fi ที่ SYS → PHONE LINK
- การเปลี่ยนหน้า HOME (พื้นหลังภาพ) ส่งข้อมูล ~170 KB ครั้งเดียว มือถืออาจกระตุกสั้น ๆ แล้วลื่นตามปกติ ; หน้าอื่นเล็กกว่ามาก
- Android บางรุ่นเลือกใช้เน็ตมือถือแทน Wi-Fi ที่ไม่มีอินเทอร์เน็ต: ต้องกด "คงการเชื่อมต่อไว้" หรือปิดข้อมูลมือถือชั่วคราว
- iOS ครั้งแรกจะถามสิทธิ์ "เครือข่ายในพื้นที่" และ "ตำแหน่ง" ต้องกดอนุญาต
- รองรับมือถือพร้อมกันสูงสุด 2 เครื่อง ; ควรเปลี่ยนรหัส Wi-Fi ก่อนใช้งานจริง
- หน้าบูต (โปสเตอร์) ไม่ถูกส่งไปมือถือ ; หลังบูตมือถือจะได้ภาพทันทีที่ต่อ

## สร้างแอป Android (.apk) ด้วย GitHub (ไม่ต้องลงโปรแกรมใด ๆ)
1. สมัคร github.com ฟรี → New repository (ตั้งเป็น Private ได้)
2. อัปโหลดทั้งโฟลเดอร์โปรเจกต์ (รวมโฟลเดอร์ `.github`) ถ้าอัปโหลดแล้วไม่เห็น `.github` ให้ Add file → Create new file ตั้งชื่อ `.github/workflows/android.yml` แล้ววางเนื้อหาจากไฟล์เดียวกัน
3. แท็บ **Actions** → **Build Android APK** → **Run workflow** → รอ ~10 นาที
4. เปิดงานที่เสร็จ (เครื่องหมายถูกเขียว) → ท้ายหน้า Artifacts โหลด **nui-gauge-apk** (ไฟล์ zip) → แตกได้ `app-debug.apk`
5. ส่งเข้ามือถือ เปิดไฟล์ → อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" → ติดตั้ง
6. เปิดแอป **NUI Gauge** ครั้งแรกอนุญาต "ตำแหน่ง" แล้วเลือก "ขณะใช้แอป" ต่อ Wi-Fi NUI-GAUGE ก่อนเปิดแอป

## ไม่มีเครื่องมือ Build / Build บน Windows ไม่ผ่าน -> ให้ GitHub สร้างเฟิร์มแวร์ให้
1. อัปโหลดโปรเจกต์ขึ้น GitHub (ดูหัวข้อสร้าง APK ด้านบน) → แท็บ **Actions** → **Build Firmware** → **Run workflow**
2. รอ ~10 นาที → โหลด **firmware-cyd_ili** (จอ ILI9341) หรือ **firmware-cyd** (จอ ST7789) ให้ตรงกับ env ที่คุณใช้อยู่
3. แตก zip ได้ `firmware.bin` (เฉพาะแอป) และ `merged.bin` (รวมทุกส่วน)
4. อัปโหลดเข้าเกจด้วย Chrome/Edge: เปิด https://espressif.github.io/esptool-js/ → Connect (เลือกพอร์ต COM ของเกจ) → ใส่ไฟล์ `merged.bin` ที่ address `0x0` → Program
   (หรือ `firmware.bin` ที่ address `0x10000` ถ้าเกจมีเฟิร์มแวร์อยู่แล้ว)
