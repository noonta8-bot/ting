# NUI ssk Remap — PGM-FI Smart Gauge (ESP32-2432S028R + Honda K-Line)

## วิธีใช้ (VS Code)
1. ติดตั้งส่วนขยาย **PlatformIO IDE**
2. File > Open Folder > เลือกโฟลเดอร์ `pgmfi-gauge`
3. กด Build (✓) แล้ว Upload (→) ต่อ USB ของบอร์ด

## หน้าจอ (UI ตามภาพ NUI SMART GAUGE — ปัดซ้าย/ขวาเปลี่ยนหน้า)
HOME แดชบอร์ดหลัก | GRID (ตาราง RPM x TPS ละเอียด + บันทึก) | PLOT | DATA | DTC | SYS | MENU
- HOME: SPEED, ECT, เกจ RPM, AFR/BAT/INJ, IAT, TPS, MAP(kPa), สถานะ ECU และเวลาที่เปิดเครื่อง
- IAT / MAP(kPa) / SPEED ยังไม่ได้ map ไบต์จาก ECU จริง -> ขึ้น "--" (โหมด DEMO จำลองให้) ส่วนวันที่ไม่มี RTC จึงไม่แสดง
หน้าบูต/รีบูตแสดงโลโก้ **NUI Remap** (แปลงจากภาพเป็น RGB565 ใน `include/splash_logo.h`; สร้างใหม่ด้วย `python3 tools/img2rgb565.py ภาพ.png include/splash_logo.h`)

## หน้า MAP : บันทึก AFR ตาม RPM x TPS แบบเรียลไทม์
- กริดละเอียดสุด **RPM 1200-12000 ทุก 100 rpm  x  TPS 0.0-72.5 ทุก 0.5** (109 x 146 ช่อง)
- แต่ละช่องเก็บค่าเฉลี่ย AFR / INJ(ms) / IGT(องศา) + จำนวนตัวอย่าง; บันทึกตามอัตราข้อมูลจริงของ ECU ในทุกหน้า (ไม่ต้องเปิดหน้า MAP ค้าง)
- แท็บ INJ / AFR / IGT สลับชนิดตาราง; กรอบขาว = ตำแหน่งสดตอนนี้
- **REC** เริ่ม/หยุดบันทึก (หยุดแล้วเซฟลง flash อัตโนมัติ) | **SAVE** เซฟ | **CLEAR** ลบ (กด 2 ครั้ง) | **FOLLOW** ตารางเลื่อนตามค่าสด
- **ZOOM 1-4**: 100rpm x0.5 / 200x1.0 / 500x2.5 / 1000x5.0 (ข้อมูลเก็บละเอียดสุดเสมอ ซูมแค่การแสดงผล)
- เลื่อนตาราง: ปัดขึ้น/ลง/ซ้าย/ขวาในตาราง หรือแตะแถบเลื่อน; ปัดที่แถบบน/ล่างเพื่อเปลี่ยนหน้า
- แตะป้าย **MAP** มุมซ้ายบน = ส่งข้อมูลทุกช่องที่มีค่าออก Serial 115200 เป็น CSV (rpm,tps,afr,inj_ms,igt_deg,count)
- TPS ในหน้าใหม่แสดงสเกล ECU 0-72.5 ให้ตรงกับแกนตาราง (ตั้ง `TPS_TILE_USE_PCT 0` ใน config.h เพื่อใช้ 0-100%)
- ความเร็ว (SPEED): ยังไม่มีไบต์ความเร็วในตารางที่อ่านอยู่ จึงแสดง "--" เมื่อต่อรถจริง (โหมด DEMO จำลองให้)

## ขาที่ใช้ (แก้ได้ใน include/config.h)
K-Line RX = IO22, TX = IO27 (CN1) ต้องผ่านวงจรแปลง K-Line และลดแรงดันเหลือ 3.3V
จอ ILI9341 HSPI, ทัช XPT2046 แยก SPI, ไฟจอ IO21

## ปรับแต่ง
- `K_HAS_ECHO` : 1 = วงจรส่งไบต์ที่ส่งย้อนกลับมา (ค่าเริ่มต้น); ถ้าไม่มี echo ให้ตั้ง 0
- `K_STRICT_CHECKSUM` : เปิดตรวจ checksum ขากลับ
- `RPM_MAX / RPM_WARN / RPM_REDLINE`, ช่วงอุณหภูมิ/แรงดัน : config.h
- สีกลับขั้ว (พื้นขาว/สีตรงข้าม) : สลับ `SCREEN_INVERT` ใน config.h (0/1); แดง-น้ำเงินสลับกัน : platformio.ini (TFT_RGB_ORDER=TFT_BGR)
- ทัชเพี้ยน : TS_MINX/MAXX/MINY/MAXY, กลับหัวจอ : SCREEN_ROTATION 3

## ทดสอบโดยไม่ต่อรถ
SYS > DEMO: ON จะจำลองค่าทั้งหมดรวมถึง DTC

## ภาษา EN / TH
- ปุ่ม **EN | TH** อยู่ที่หน้า **MENU** (มุมขวาบน) และหน้า **SYS** (แถว LIGHT ขวาสุด) — จำค่าไว้หลังรีสตาร์ท
- ข้อความแปลอยู่ในตาราง `TH_TR` / `TH_WORDS` ใน `src/ui.cpp` (เพิ่มคำใหม่ได้) ส่วนศัพท์เทคนิค RPM/TPS/AFR/INJ/IGT คงเป็นอังกฤษ
- ฟอนต์ไทยบิตแมปสร้างด้วย `python3 tools/gen_thai_font.py /usr/share/fonts/opentype/tlwg/Loma.otf include/thai_font.h` (Loma — ฟอนต์เสรี)
- หน้า GRID บันทึกอัตโนมัติเมื่อเปิดเครื่อง (REC เปิดเป็นค่าเริ่มต้น) และเซฟลง flash ทุก 2 นาที

## หน้าบูต/รีบูต (โปสเตอร์ ช่างแชน)
- ภาพ "สิทธิ์เสียก" ถูกแปลงเป็น RGB565 ขนาด **340x240** ใน `include/splash_chang.h` (ภาพ 4:3 ย่อให้สูง 240 แล้วเติมขอบดำข้างละ 10px); จอจริงกว้าง 320 จึงแสดงกึ่งกลางและตัดขอบดำส่วนเกินออก
- สร้างใหม่: `python3 tools/img2splash.py ภาพ.jpg include/splash_chang.h` (ปัดสีใกล้สุด + dither เพื่อให้สีตรงต้นฉบับที่สุด) ; ดูตัวอย่างที่ `include/splash_chang_preview.png`
- กลับไปใช้โลโก้ NUI เดิม: ตั้ง `SPLASH_USE_POSTER 0` ใน config.h
- สีแดง/น้ำเงินสลับ (ตรวจจากรูปจอจริง): เปิด `-DTFT_RGB_ORDER=TFT_BGR` ใน env `cyd` ของ platformio.ini แล้ว ทำให้ทั้งหน้าบูตและ UI ทุกหน้าแสดงสีตรง

## อัปเดตล่าสุด

- **แกน TPS ของตาราง GRID**: 25 จุด 0.0 0.4 0.8 1.2 1.8 2.4 3.2 4.4 5.7 7.4 9.2 11.0 13.0 15.0 18.0 22.0 26.0 30.0 34.9 40.0 48.1 57.3 66.9 71.9 72.5 (ไฟล์แมพเก่าจะถูกล้างอัตโนมัติ)
- **DTC**: ปุ่ม READ ลองซ้ำเอง และเริ่มเซสชัน K-Line ใหม่อัตโนมัติถ้าอ่านไม่ได้ (ไม่ต้องปิด/เปิดสวิตช์)
- **ตั้งค่าแจ้งเตือน** (SYS > ALERT SETTINGS)
  - เครื่องร้อน: ตั้งอุณหภูมิ 60-150 C ได้อิสระ, เปิด/ปิดได้ ; เตือนที่หน้า HOME (แบนเนอร์ HIGH TEMP + ECT แดง + หัวจอกระพริบ) และแถบบนของหน้าอื่น
  - เปลี่ยนเกียร์: ตั้งรอบ 3000-12000 ได้อิสระ, เปิด/ปิดได้ ; ถึงรอบแล้วแบนเนอร์ SHIFT UP! กระพริบถี่ที่หน้า HOME
  - ค่าที่ตั้งถูกจำไว้ใน flash (Preferences) ไม่หายตอนดับเครื่อง
- **ฟอนต์อังกฤษ/ตัวเลขสไตล์สปอร์ต** (include/race_font.h, สร้างจาก Inter ExtraBold Italic ด้วย tools/gen_race_font.py) ; ภาษาไทยใช้ฟอนต์เดิม
- **หน้า GRID แสดงครบหน้าเดียว** (ไม่มีซูม/เลื่อน/ตามสด): 25 คอลัมน์ TPS ครบทุกค่า x 12 แถว RPM (กลุ่มละ 1000 rpm) ; ตัวเลขในช่อง = ค่า x10 (AFR 14.7 -> 147) แตะช่องเพื่อดูค่าจริง ; ปุ่มล่าง: BACK / SAVE / CLEAR / REC

## หน้า HOME แบบภาพสำเร็จรูป (สวยเท่าภาพต้นฉบับบนจอ 16 บิต)
- เปิด/ปิดที่ `HOME_USE_BG` ใน `include/config.h` (1 = ใช้ภาพพื้นหลัง, 0 = วาดกรอบสดแบบเดิม ประหยัด flash ~215 KB)
- `include/home_bg.h` = พื้นหลัง 320x240 RGB565 + dithering (กรอบนีออน ลายเส้น โลโก้ วงเกจ) ที่ลบตัวเลข/ค่าที่เปลี่ยนออกแล้ว, ภาพแถบรอบ RPM "ติด", แผนที่ลำดับขั้น และภาพกรอบ ECT สีแดง (เครื่องร้อน)
- ตอนรัน: ตัวเลขวาดด้วยฟอนต์ anti-alias 4 บิต (`include/num_font.h`) ผสมกับพื้นหลังจริงทีละพิกเซล, แถบรอบ RPM คัดลอกเฉพาะขั้นที่เปลี่ยน (96 ขั้น), แถบ AFR/INJ วาดทับ, กรอบ ECT สลับเป็นสีแดงเมื่อเครื่องร้อน
- MAP / IAT ตั้งแต่ 100 ขึ้นไปแสดงเป็นจำนวนเต็ม (147 แทน 147.0) ให้ตัวเลขพอดีกรอบ
- สร้างพื้นหลังใหม่: `python3 tools/make_home_bg.py assets/home_target.png include/home_bg.h --max=12 --warn=8.5`
  (`--max` ต้องตรงกับ `RPM_MAX/1000` ใน config.h ไม่งั้น build จะ error ด้วย static_assert)
- สร้างฟอนต์ตัวเลขใหม่: `python3 tools/gen_num_font.py /usr/share/fonts/opentype/inter/Inter-ExtraBoldItalic.otf include/num_font.h`
- ถ้า build แล้วเฟิร์มแวร์ใหญ่เกินพาร์ติชัน (default.csv = 1.25 MB ต่อชุด) ให้ตั้ง `HOME_USE_BG 0` หรือเปลี่ยนพาร์ติชันเป็น `huge_app.csv`
